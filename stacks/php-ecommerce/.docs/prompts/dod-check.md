## Правила проверки

- Проверяй только по коду который видишь — не предполагай что что-то работает
- Если критерий невозможно проверить статически (например «запись появляется в БД») — отмечай ⚠️ Требует ручной проверки
- Если таск не затрагивает какой-то раздел DoD Global (например нет форм) — пропускай раздел целиком
- Будь конкретным: указывай файл и строку где проблема
- Не предлагай рефакторинг — только проверка DoD
