# Промпт: Создание таска

Скопируй текст ниже и отправь в чат Claude Code (в VS Code).

---

Нужно создать TASK.md для следующего таска.

Прочитай эти файлы:
- @CLAUDE.md — архитектура и правила проекта
- @.docs/phases/phase-N.md — текущая фаза (укажи нужный номер)
- @.docs/dod-global.md — глобальные критерии готовности
- @TASK-example.md — шаблон структуры таска

Затем:
1. Найди первый таск со статусом ⏳ Ожидает в phase-N.md
2. Составь список конкретных файлов которые нужно создать или изменить
3. Определи что явно не входит в этот таск (out of scope)
4. Напиши проверяемые критерии DoD
5. Жди моего подтверждения
6. После подтверждения перезапиши TASK.md

Не пиши код. Только планирование.
Жди подтверждения перед записью файла.
