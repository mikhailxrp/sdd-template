## Цикл разработки

0. Новый проект и есть ТЗ/скриншоты → промпт из
   `.docs/prompts/project-init.md` → заполняет `prd.md` и
   `database.md` (один раз, до первой фазы)
1. Открыть `.docs/phases/_status.md` — понять какая фаза в работе
2. Открыть `TASK.md` — прочитать что делать сегодня
3. Если нет активного таска → скопировать промпт из `.docs/prompts/task-init.md`
4. Сказать агенту: «Реализуй задачу из TASK.md. Следуй CLAUDE.md»
5. Проверить DoD вручную в браузере
6. Повторить шаги 3-5 для следующего таска
7. Фаза готова → попросить агента создать `phase-N-report.md`
8. Обновить `_status.md`

↑ повторить для следующей фазы
