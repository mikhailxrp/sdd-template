# Промпт: Создание новой фазы

Скопируй текст ниже и отправь в чат агента (Claude Code или Antigravity).

---

Нам нужно спланировать новую фазу разработки.

Прочитай эти файлы:

- @AGENTS.md — архитектура и правила проекта (ядро + включённые пакеты)
- @.docs/prd.md — полный список функциональности и роадмап
- @.docs/database.md — схема БД (PostgreSQL)
- @.docs/capabilities.md — подсказки по фазам и рискам включённых пакетов (если файл существует)
- @.docs/phases/_status.md — какие фазы уже есть и в каком статусе
- @.docs/phases/ — прочитай существующие `phase-N.md`, чтобы понять, что уже сделано

Затем:

1. Определи следующую фазу на основе роадмапа из `prd.md`, статусов из `_status.md` и подсказок из `capabilities.md`.
2. Предложи, что входит в фазу — коротко опиши цель и вертикальный срез (что можно будет проверить после завершения фазы).
3. Раздели фазу на таски (каждый таск = 1–2 дня, 4–7 файлов). Учитывай, что каждый таск с бизнес-логикой включает Actions и тесты Pest (`CORE-1`, `CORE-16`), а изменения схемы БД идут миграциями (`CORE-8`).
4. Для каждого таска укажи: цель, файлы, DoD и способ проверки каждого шага (Pest / Pint / браузер).
5. Жди моего подтверждения.
6. После подтверждения создай файл `.docs/phases/phase-N.md` и обнови статус в `.docs/phases/_status.md`.

За основу структуры возьми @.docs/phases/phase-example.md

Не пиши код. Только планирование.
Жди подтверждения перед созданием файла.
