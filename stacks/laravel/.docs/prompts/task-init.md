# Промпт: Создание таска

Скопируй текст ниже и отправь в чат агента (Claude Code или Antigravity).

---

Нужно создать `TASK.md` для следующего таска.

Прочитай эти файлы:

- @AGENTS.md — архитектура и правила проекта (ядро + включённые пакеты)
- @.docs/rules/laravel.md — детали контрактов Laravel, Livewire, Filament, Pest
- @.docs/phases/phase-N.md — текущая фаза (укажи нужный номер)
- @.docs/dod-global.md — глобальные критерии готовности
- @TASK-example.md — шаблон структуры таска

Затем:

1. Найди первый таск со статусом ⏳ Ожидает в `phase-N.md`.
2. Составь список конкретных файлов, которые нужно создать или изменить (миграции, модели, Actions, Form Requests, Policies, Livewire/контроллеры, Filament-ресурсы, тесты Pest).
3. Определи, что явно не входит в этот таск (out of scope).
4. Напиши проверяемые критерии DoD и на каждый шаг укажи, чем он будет проверен (тест `vendor/bin/pest`, `vendor/bin/pint --test`, ручная проверка в браузере, конкретный пункт `dod-global.md`).
5. Жди моего подтверждения.
6. После подтверждения перезапиши `TASK.md`.

Не пиши код. Только планирование.
Жди подтверждения перед записью файла.
