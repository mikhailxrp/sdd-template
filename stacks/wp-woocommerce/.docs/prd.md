## Возможности (capabilities)

Источник истины по составу пакетов. Блоки правил, таблицы/сущности БД и критерии DoD включённых пакетов попадают в `AGENTS.md`, `.docs/database.md` и `.docs/dod-global.md` командой `/sdd-capabilities`. Выключенного пакета в проекте нет: его правил и таблиц не добавляй «по аналогии».

| Пакет | Статус | Параметры |
|-------|--------|-----------|
| woocommerce | вкл / выкл | < типы товаров (простые/вариативные), валюта, штатные доставка/оплата, HPOS > |
| leads | вкл / выкл | < формы заявок, получатели уведомлений (почта / Telegram / CRM) > |
| custom-plugin | вкл / выкл | < slug плагина, какие CPT/интеграции/таблицы выносятся из темы > |
| payments-ru | вкл / выкл | < шлюз РФ (ЮKassa / Сбер / Т-Банк), фискализация 54-ФЗ > |
| shipping-ru | вкл / выкл | < службы доставки (СДЭК / Почта России / Boxberry), расчёт тарифов > |
| onec-sync | вкл / выкл | < конфигурация 1С, формат обмена (CommerceML / REST), периодичность > |

Связи между пакетами (описаны в заголовке каждого пакета; проверяются при сборке):
- пакет с зависимостью нельзя включить без неё (`payments-ru`, `shipping-ru`, `onec-sync` требуют `woocommerce`);
- если штатных способов оплаты и доставки WooCommerce достаточно — `payments-ru` и `shipping-ru` остаются `выкл`.

Смена состава: исправь таблицу, запиши причину в `.docs/dev-log.md` и перегенерируй затронутые блоки через `/sdd-capabilities`.
