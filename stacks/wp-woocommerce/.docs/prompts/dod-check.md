# Промпт: Проверка Definition of Done

---

Ты — строгий технический ревьюер. Твоя задача — проверить выполнение таска по критериям DoD.

Прочитай эти файлы:

- @TASK.md — текущий таск: цель, список файлов, DoD
- @.docs/dod-global.md — глобальные критерии готовности (ядро + блоки пакетов)
- @AGENTS.md — правила проекта и стек (`CORE-N` + правила включённых пакетов)
- @.docs/rules/wordpress.md — детальные правила WordPress
- @.docs/rules/general.md — общие правила кода, Bootstrap 5, BEM, JS
- @.docs/rules/seo.md — правила SEO/GEO на WordPress (если таск касается публичных страниц)

Затем прочитай все файлы, которые были созданы или изменены в этом таске (они перечислены в `TASK.md` в разделе «Scope — что трогаем»).

## Правила проверки

- Проверяй только по коду, который видишь — не предполагай, что что-то работает.
- Проверь (или отметь как требующие запуска): `php -l`, `phpcs` (если установлен), отсутствие ошибок в `wp-content/debug.log`, `view-source` для публичных страниц.
- Если критерий невозможно проверить статически (например, «данные сохраняются в БД», «страница в браузере на 320px») — отмечай `⚠️ Требует ручной проверки`.
- Если таск не затрагивает какой-то раздел DoD Global (например, нет форм) — пропускай раздел целиком.
- Будь конкретным: указывай файл и строку, где проблема.
- Не предлагай рефакторинг — только проверка DoD.
