# Промпт: Инициализация проекта из ТЗ

Скопируй текст ниже и отправь в чат агента (Claude Code или Antigravity), приложив
ТЗ и макеты/вёрстку (если есть) прямо в том же сообщении.

> Если используешь полный SDD-конвейер со слэш-командами, этот шаг заменяется
> последовательностью `/sdd-init` → `/sdd-capabilities` → `/sdd-schema` → `/sdd-roadmap`.

---

Я даю тебе ТЗ на новый проект (текстом и/или макетами интерфейса).
Нужно перевести это в документацию проекта, по которой дальше пойдёт
разработка на WordPress + WooCommerce.

Прочитай эти файлы:

- @AGENTS.md — архитектура и правила ядра WordPress
- @.docs/database.md — базовая модель данных WordPress (MySQL/MariaDB, CPT, Redux)
- @.docs/dod-global.md — глобальные критерии готовности
- @.docs/prd.md — текущий (пустой) шаблон
- @capabilities/_format.md — формат подключаемых пакетов возможностей (если папка `capabilities/` ещё на месте)

Затем:

1. Разбери ТЗ и макеты (`00-input/design/`, `direction.md`, если приложены). Если что-то неочевидно или допускает несколько трактовок — покажи варианты и спроси, не выбирай молча.
2. Определи, какие пакеты возможностей (`woocommerce`, `leads`, `custom-plugin`, `payments-ru`, `shipping-ru`, `onec-sync`) нужны проекту по ТЗ, и собери недостающие параметры из их разделов `## Параметры`. Если нужен пакет со `status: stub`, явно предупреди об этом.
3. Подготовь заполнение `.docs/prd.md`: о продукте, роли WP, параметры окружения (OpenServer, text-domain, SEO-плагин), таблица «Возможности», страницы/разделы, функциональные требования, вне скоупа, критерии приёмки, черновой роадмап по фазам.
4. После согласования таблицы «Возможности» в `.docs/prd.md` — выполни сборку пакетов по инструкции `/sdd-capabilities` (`workflow/sdd-capabilities.md`), чтобы блоки включённых пакетов попали в `AGENTS.md`, `.docs/database.md`, `.docs/dod-global.md` и `.docs/capabilities.md`.
5. Сравни сущности из ТЗ с получившейся моделью данных в `.docs/database.md`:
   - какие CPT, таксономии и метаполя Redux Framework добавить
   - какие кастомные SQL-таблицы (`dbDelta`) действительно необходимы сверх `wp_posts`/`wp_postmeta`
6. Отдельно перечисли всё, что в ТЗ выходит за рамки ядра и пакетов (сторонние плагины WP/WooCommerce, внешние API, нестандартный деплой) — уточни у меня, а не придумывай решение сам.
7. Жди моего подтверждения.
8. После подтверждения — обнови `.docs/prd.md`, собери пакеты и внеси согласованные правки в `.docs/database.md`.

Не пиши код. Только анализ и документация.
Жди подтверждения перед записью файлов.

---

## После этого шага

Когда `prd.md`, пакеты (`capabilities.md`) и `database.md` готовы — переходи к
`.docs/prompts/phase-init.md`, чтобы спланировать Фазу 0.
