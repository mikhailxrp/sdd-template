# Журнал разработки (dev-log)

> Фиксируй здесь итоги сессий, архитектурные решения во время написания кода, установку новых плагинов и найденные нюансы окружения (OpenServer / shared-хостинг).
> Решения этапа планирования ТЗ → SDD лежат в `.docs/planning-log.md`.

---

## Формат записи

```markdown
### YYYY-MM-DD — < Фаза / Таск >

- **Сделано:** …
- **Решения:** … (например, добавлен плагин X, потому что …)
- **Проблемы / нюансы:** …
- **Следующее:** …
```
