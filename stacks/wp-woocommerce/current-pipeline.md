## Цикл разработки

0. Новый проект и есть ТЗ → прогони конвейер документации:
   `/sdd-init` → `/sdd-capabilities` → `/sdd-schema` → `/sdd-roadmap` → `/sdd-review`
   (или используй `.docs/prompts/project-init.md` при ручном старте)
1. Открыть `.docs/phases/_status.md` — понять, какая фаза в работе
2. Открыть `TASK.md` — прочитать, что делать сегодня
3. Если нет активного таска → скопировать промпт из `.docs/prompts/task-init.md`
4. Сказать агенту: «Реализуй задачу из TASK.md. Следуй AGENTS.md»
5. Проверить `php -l` (и `phpcs`, если настроен), `wp-content/debug.log`, браузер на OpenServer и DoD (`.docs/prompts/dod-check.md`)
6. Повторить шаги 3–5 для следующего таска
7. Фаза готова → попросить агента создать `phase-N-report.md`
8. Обновить `_status.md`

↑ повторить для следующей фазы
