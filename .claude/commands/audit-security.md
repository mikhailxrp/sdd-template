## Проходи `dod-global.md` пункт за пунктом, не пропуская

Для каждого пункта раздела «Безопасность» — конкретное действие,
не общая оценка «выглядит нормально»:

**Изоляция данных по ролям и id.** Залогинься под Покупателем A,
запомни id его заказа. Залогинься под Покупателем B, подставь в URL
id заказа A. Ожидание: отказ. Повтори для всех пар ролей, где это
применимо (не только «гость vs админ»).

**CSRF.** Найди все формы с POST. Для каждой — отправь запрос без
CSRF-токена или с чужим токеном напрямую (curl/Postman, минуя форму).
Ожидание: отказ, а не тихое принятие.

**SQL-инъекции.** В каждое поле поиска/фильтра/сортировки, принимающее
пользовательский ввод, подставь `' OR '1'='1`, `'; DROP TABLE--` и
похожие. Ожидание: ошибка валидации или экранированный запрос, не
SQL-ошибка в ответе и не неожиданная выдача всех записей.

**XSS.** В поля, которые потом отображаются другим пользователям
(отзыв, комментарий, имя в профиле) — подставь `<script>alert(1)</script>`.
Открой страницу, где это должно отобразиться. Ожидание: текст, не
выполнившийся скрипт.

**Цена и остаток с клиента.** Через инструменты браузера/curl —
подмени цену товара в запросе оформления заказа. Ожидание: сервер
берёт цену из БД, не из присланных данных, итоговая сумма не меняется.

**Rate limiting.** Пошли 20+ запросов логина подряд с неверным
паролем. Ожидание: блокировка после N попыток, не бесконечные
попытки.

**Загрузка файлов** (если применимо). Попробуй загрузить `.php`-файл
с расширением `.jpg`, посмотри, что реально сохраняется и как
проверяется тип. Проверь права на `public/uploads/.htaccess`.

**Сессии.** Залогинься, посмотри ID сессии до и после логина —
должен смениться (`regenerateSession()`), а не остаться прежним.

**Утечка информации при логине.** Введи существующий email с неверным
паролем и несуществующий email — тексты ошибок должны быть
одинаковыми.

Остальные пункты `dod-global.md`, не перечисленные выше явно, —
проверяй по той же логике: не читай код и не верь ему на слово, а
действием подтверждай, что защита реально срабатывает.
