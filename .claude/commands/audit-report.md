Эта команда ничего не проверяет сама — только сводит уже готовые
отчёты `/audit-security`, `/audit-functional`, `/audit-integration`,
`/audit-seo` (они должны быть выполнены раньше, в этой же сессии или
переданы текстом).

## Собери `.docs/audit-report.md`

```markdown
# Аудит готовности к продакшену

Дата: [дата]

## Итог одной строкой

[Готов / Не готов] к запуску. [N] критичных находок,
[N] высоких, [N] средних, [N] низких.

[все находки уровня "Критично" из всех трёх отчётов, без сокращений]

[...]

## Средние и низкие — списком, без разворачивания

[таблица: ID | название | откуда]

[что не удалось проверить в текущем окружении, из всех трёх отчётов]

## Сводка по разделам
```

## Правила сведения

Не переписывай находки своими словами — переноси как есть из
исходных отчётов, только группируй по серьёзности вместо группировки
по виду аудита. Если одна и та же проблема упомянута в двух отчётах
разными словами (например, найдена и в security, и в integration) —
не дублируй, укажи один раз со ссылкой на оба источника.

Не смягчай формулировки и не добавляй оптимистичных обобщений вроде
«в целом всё хорошо» — итог одной строкой должен быть ровно тем, что
показывают цифры, без интерпретации.
